# 站位、朝向与动作

这一步在流程里出现两次：**阶段 2 由你从原文推断后逐镜写出**，表后紧跟一句问用户要不要改；
**阶段 4 拿到编号后再按号回填复核一次**。缺了它，生成结果会退化成人物并排站、一起正面朝镜头的
新闻联播式构图——没有指定朝向时，模型会把每个已编号的主体摆成同一朝向的证件照。

## 怎么从原文推断

先读原文里这些可直接落地的线索，再动笔：

- **谁对谁说话** → 说话人面向听话人，听话人在画面里给侧脸或背影。
- **动词带方向**：走进、退后、回头、转身、跪下、递出、拔剑、推开门 → 直接变成动作与朝向。
- **空间词**：门外、柜台后、山崖边、身后、树下 → 直接变成占位。
- **视线词**：看向、盯着、背对着、别过脸 → 直接变成朝向与视线。
- **道具在手**：捧着、背着、横放、握紧 → 决定手与身体状态。
- **群像**：众人、身后一片哗然 → 放到中后景，别和主角挤在同一平面。
- **原文已经写明位置或朝向时不得改**（例如原文写「背对着他」，就不能写成正面相对）。
- 推不出来的按下面的默认规则补，不要留空。

## 逐镜写清五项

1. **占位**：每个人在画面里的位置（画面左/右/中、前景/中景/后景、离镜头远近、谁被谁挡住）。
2. **朝向**：身体朝哪（正对镜头 / 四分之三 / 侧身 / 背对，以及朝画面哪一侧）。
3. **视线**：看谁、看哪里（对方的脸、手里的东西、画面外的方向）。
4. **动作与状态**：站、坐、倚、走、弯腰；谁在动、谁不动；谁入画、谁出画。
5. **互动关系**：谁面向谁、谁背对谁、谁和谁之间隔着什么（一张柜台、一扇门、一根柱子）。

写成一行的粒度参考：

```text
站位 / 朝向 / 动作：叶君临在画面右侧前景，侧身站、四分之三背对镜头，视线落在木盒上；
青袍老者在画面左侧中景，正对叶君临、只有侧脸给镜头，双手托盒向前递出；两人隔一步距离，无人正对镜头。
```

## 输出后必须问一句

分镜表输出后紧跟一句，别省：

```text
上面的站位、朝向、动作是我按原文推断的：哪一镜要改？不改我就按这版写视频提示词。
```

- 用户指出某一镜要改时只改那一镜，其余保持。
- 用户说「你定」时，按下面的默认规则再复核一遍；原文已写明的位置或朝向不得推翻。
- 用户改完的版本是硬约束，写进正文时原样落地。

## 阶段 4 按号回填

拿到编号后，把站位表里的名字换成号再输出一次，让用户核对同一件事：

```text
分镜 2：<Subject 1> 在画面右侧前景，侧身、四分之三背对镜头，视线落在 <Picture 3> 上；
<Subject 2> 在画面左侧中景，正对 <Subject 1>、侧脸给镜头。
```

此刻看到的版本就是写进视频提示词的版本，之后不再改。

## 用户没写时的默认规则

默认目标是把画面拍成「实拍现场」，不是拍成「合影」：

- **不排成一排**：同框的主体之间要有角度差。一个人正对镜头，另一个人就必须侧身或背对。
- **不全体正面朝镜头**：除非用户点名要合影、队列、仪式、受审这类正面构图。
- **给纵深**：用前景/中景/后景分层，别让所有人站在同一平面上。
- **朝向跟着戏走**：说话人面向听话人；听的人在画面里给侧脸或背影，不抢正脸。
- **不说话的人**：优先安排他出画或背身；实在要留在画面里，就在正文里明写他不说话。
- **动作落在谁身上**：本镜动作的承担者占前景或视觉重心，其他人退到中后景。

## 写进正文时的英文对照

| 中文 | 正文写法 |
|---|---|
| 正对镜头 | facing the camera / frontal to the lens |
| 四分之三侧 | three-quarter turn toward the camera |
| 侧身，朝画面左 | in profile, facing screen left |
| 背对镜头 | back to the camera |
| 仰视 / 俯视某人 | looking up at / looking down at |
| 视线落在某人身上 | his eyeline fixed on the face of `<Subject 2>` |
| 视线落在画面外 | his gaze directed off-screen left |
| 画面左 / 画面右 | screen left / screen right |
| 前景 / 中景 / 后景 | foreground / midground / background |
| 被某人挡住 | partially occluded by `<Subject 1>` |
| 站在某人左后方 | standing behind and to the left of `<Subject 2>` |

## 左右与轴线的纪律

- **裸写的左/右一律指画面左右**（观众看到的左右）。指人物自身的左右必须带上主体：
  `his left hand` / `her right shoulder`。
- 同一条对话轴上的正反打不能翻面。要翻面必须有一个新的可见动作作依据（起身、转身、走过某物），
  并把这个动作写进正文。
- 站位与朝向会跨镜延续。同一人在相邻镜头里的朝向变了，正文里要有触发它的动作。

## 校验

- 每个已编号的人物在**每个出场镜头**里都有占位与朝向；缺项按默认规则补，并标出哪些是补的。
- 分镜表输出后已经问过用户是否要改；用户改过的已原样落位。
- 台词与朝向一致：说话人面向听话人，不是面向镜头。
- 每个镜头里至少有一个主体不正面朝镜头（除非用户点名要正面构图）。
- 站位与朝向是每镜的事，**不进 subject_definitions**——定义段只锁身份。
