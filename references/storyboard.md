# 分段与分镜元素

## 分段：按情节切，不按字数切

一个分镜 = 一个可拍摄单元 = 一个能看见的戏剧动作。切法：

- 先找**动作单元**：谁、在哪、做了什么、落到什么结果。一个单元一段。
- 段界优先落在三类位置：场景或时间变化（地点、时段、天气换了）；动作落点（一个动作完成并改变状态）；
  对白交锋的回合边界（一人说完、另一人接）。
- 每段都要有写得出的进入画面和出去画面。只写得进写不出的段落说明切错了：把没交代的动作并回去或重新切。
- 一段不装两场戏；也不要把同一场戏按句号切成碎片。对白密集处按“一问一答一反应”切。
- 参考区间（不是硬指标）：一段通常 1-4 句原文；对白回合多可以更短；环境铺陈可以更长。

分段产物：

```markdown
## 分段总览

| 段 | 原文定位 | 情节功能 | 场景 / 时间 | 预计时长 |
|---|---|---|---|---|
| 1 | 首句…末句 | 主角抵达驿站，第一次与掌柜对上 | 渡口驿站 · 夜 · 雨 | 3.5s |
| 2 | 首句…末句 | 掌柜推符牌并拒船 | 渡口驿站 · 夜 · 雨 | 3.5s |
```

### 小说特有的两件事

- **心理描写要变成可见画面**：原文写“他忽然明白过来”，分镜要落到一个可见证据（手停在半空、瞳孔一缩、
  杯子没端稳）。原文写“三年了，他终于回来了”，只有画面上能兑现的部分进画面，其余进旁白或直接不写。
  不要把小说原句当画面字幕塞进提示词。
- **白描与叙事框架词要分开**：可拍的是白描（光线、物体、身体动作、可听的声响）；“心里翻江倒海”
  “气氛凝固”这类框架词必须翻译成具体画面或声音，翻不动的交回用户确认，不要硬写。

## 分镜元素表

逐镜输出，字段固定：

```markdown
## 分镜 2 ｜ 掌柜推符牌

- 原文依据：「南边的船，今夜不走。」
- 情节摘要：掌柜把符牌推过柜台，开口拒了南下的船。
- 进入 → 出去：掌柜的手还压在账本上 → 符牌停在柜台中线，两人隔柜台对视
- 分镜人物：驿站掌柜（发声）、沈砚（在场沉默）
- 分镜场景：渡口驿站 · 夜 · 雨 · 暖色油灯
- 分镜道具：青铜符牌（特有，理由：锈蚀旧物，铸有渡号纹样，后文靠它认人）
- 站位 / 朝向 / 动作：沈砚在画面右侧前景，侧身站、四分之三背对镜头，视线落在柜面上的符牌；驿站掌柜在画面左侧中景柜台后，正对沈砚、只有侧脸给镜头，推符牌的手收回后压在账本上；两人隔一张柜台，无人正对镜头
- 环境声 / 音效：雨打屋檐、门轴吱呀、铜牌擦过柜面
- 对白：「南边的船，今夜不走。」（驿站掌柜）
- 预计时长：3.5s
```

- 人物写名字或原文称谓，标出**是否发声**。发声者才进说话人编号；沉默的人在镜头里要明确不语。
- 场景写地点 + 时段 + 天气/光态，不写“房间”“外面”这类无信息量词。
- 道具只列通过下面筛选标准的那些，并逐项写理由。
- 站位 / 朝向 / 动作由你从原文推断后逐镜写出，不能留空；原文已写明位置或朝向的不得改。推断线索、默认规则与英文对照见 [站位与朝向](blocking.md#怎么从原文推断)。
- 整张分镜表输出后紧跟一句，问用户要不要改站位、朝向或动作，然后才进下一步。

### 道具筛选标准

只有**小说特有的个性化物品**才单独出提示词：

- **列**：丹药、佩剑、法器、令牌、符牌、家传之物、有来历或有刻字的物件、剧情关键物证。
- **不列**：苹果、香蕉、电脑、鼠标、雨伞、茶杯这类常见普通物品。
- **例外**：原文对普通物品有特殊描写时（独特外观、刻字、特殊状态、被点名的来历）按“特有”处理，
  并写清它够格的原因。
- **一句话判据**：换一件同类的普通物件，剧情和识别是否受影响？不影响 → 不列。
- **每列一项都给理由**，理由要能被用户反驳；给不出理由的就不该列。

## 风格与语言：先问再写

写图片提示词之前，用一次提问拿齐这两项，不要边写边猜：

1. **画风偏好**：默认 `超写实真人商业摄影质感`。常见可选：国漫二次元、二维动态漫、风格化三维、
   水墨笔触、Q版表达、定格动画，或用户自己给的具体风格词。
2. **提示词语言**：默认中文；用户要求英文或其他语言时按其要求，并在本次任务内保持一致。

用户已经给了风格词就必须用它，不要替换成默认的 cinematic realistic。风格只写在提示词开头的风格句里，
不用它顶掉身份锚点。

## 图片提示词配方

一条提示词 = 一个元素 + 一个用途。三类通用要求：

- 开头先写**对象与用途**（人物设定图 / 场景空镜 / 道具参考图），再写稳定特征；风格词不占开头。
- 只写这一张图能同时成立的要求；互斥状态不要并存（“衣裳干爽”和“浑身湿透”不能同图）。
- 不用质量词堆砌顶替事实：不写“高清、精美、顶级、完美五官、大师之作”。
- **文字政策**：画面里的招牌、刻字、标签要原样给出文字并写明位置；不需要文字时明确写“不出现任何文字、水印、logo”。
- 排除项只写最可能出现的误读，不写愿望清单。
- 正文可直接复制：不含占位符、文件路径、流程说明和 QA 结论。

### 人物

分两层，先身份后造型：

1. **身份层**（换一套衣服还认得出来的）：年龄感、面部轮廓、眉眼鼻唇的相对特征、肤色、
   固定发质发色与发际、不会随场景消失的痣/疤/身体特征、与身份绑定的配饰。
2. **造型层**（会随剧情变的）：发型整理方式与盘法、服装款式/层次/领口袖口/材质/主次色/纹样、鞋、
   妆面、临时配饰、污渍与新旧伤。
3. **呈现**：三视图 / 头肩 / 全身三分之二身，姿态、表情范围、背景政策与光向。

不要为了“独特”新造疤痕、异色瞳、纹身；也不要替原文没写明性别的角色强行定性。

### 场景

按“空间结构 → 关键陈设与材质 → 主色 → 标志物 → 光线与天气 → 视角”写。
粒度参考：`exposed brick wall, an orange tufted sofa with patterned pillows, a neon sign, and a wooden coffee table`。
只写“雪景”“客栈”“房间”等于没写。

### 道具

按“形制与尺寸比例 → 材质与做旧 → 标记/刻字/纹样（可读文字原样照抄）→ 当前状态（开合、破损、染血）
→ 比例参照物 → 背景与光线”写。说明它在剧情里怎么被认出来，不要写成静物摄影。

## 编号位

**号由用户给，不由你定。** 拿到全部元素后，按下面的格式向用户索取：

```text
请给每个元素指定位置，例如：
沈砚为1号位、驿站掌柜为2号位、渡口驿站为3号位、赤霄剑为4号位、青铜符牌为5号位
```

- 列出时按 **人物 → 场景 → 道具** 分组，并标注每个元素出现在哪些分镜，方便用户核对。
- 同一身份/场景/道具在全集只用**一个号**，跨镜复用，不要每镜重新编号。
- 编号决定标签：**人物写 `<Subject N>`，场景与道具写 `<Picture N>`**（N 为对应号）。
- 收到编号后逐项校验：每个出现过的元素都有号；号不重复、不跳号；人物与场景/道具没有被混编。
  缺号、重号、有元素没被点到时回去问用户，不猜、不代为补号。
- 用户明确要求按单镜重新编号时按其要求执行，并在产物里说清每镜的本地编号。
- 编号确认后把站位 / 朝向 / 动作按号回填再输出一次供用户核对，见 [站位与朝向](blocking.md#阶段-4-按号回填)。
